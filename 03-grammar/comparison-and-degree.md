# 비교·정도·추측 표현 — 2026-11-17

## 1. '~랑 비교해서'의 세 가지 표현

| 표현 | 병음 | 의미·용법 |
|---|---|---|
| 跟 A 比起来 | gēn A bǐ qǐlái | A와 비교해서 (회화에서 자연스러움) |
| 和 A 相比 | hé A xiāngbǐ | A와 비교하면 (회화·문어) |
| 与 A 相比 | yǔ A xiāngbǐ | A와 비교하면 (상대적으로 격식 있는 문어) |
| X 比 Y + 형용사 | X bǐ Y… | X가 Y보다 ~하다 |

### 원문 예문

**跟去年比起来，今年的销售额增长了很多。**  
*Gēn qùnián bǐ qǐlái, jīnnián de xiāoshòu'é zēngzhǎng le hěn duō.*  
작년에 비해 올해 매출이 많이 늘었어요.

**和首尔相比，这里的物价更便宜一些。**  
*Hé Shǒu'ěr xiāngbǐ, zhèlǐ de wùjià gèng piányi yìxiē.*  
서울에 비해 이곳의 물가가 조금 더 저렴해요.

**今天的天气比昨天好多了。**  
*Jīntiān de tiānqì bǐ zuótiān hǎo duō le.*  
오늘 날씨가 어제보다 훨씬 좋아졌어요.

**这家店比别的店都好吃。**  
*Zhè jiā diàn bǐ bié de diàn dōu hǎochī.*  
이 가게가 다른 가게보다 더 맛있어요.

**我比他高。**  
*Wǒ bǐ tā gāo.*  
나는 그보다 키가 커요.

### 만들기

- A 比 B + 形容词: `这个比那个贵` (이게 저것보다 비싸요)
- A 比 B + 形容词 + 수량: `高尔夫手套比包贵12块` (장갑이 가방보다 12위안 비싸요)

## 2. 比较 (bǐjiào)의 두 가지 뜻

### 부사: 비교적, 꽤, 제법

- **这个比较便宜。** *Zhège bǐjiào piányi.* — 이건 비교적 저렴해요.
- **今天比较冷。** *Jīntiān bǐjiào lěng.* — 오늘은 제법 춥네요.
- **我比较喜欢这个。** *Wǒ bǐjiào xǐhuan zhège.* — 저는 이게 더 마음에 들어요.

### 동사: 비교하다

- **别总是跟别人比较。** *Bié zǒngshì gēn biérén bǐjiào.* — 자꾸 다른 사람과 비교하지 마세요.
- **你可以比较一下价格。** *Nǐ kěyǐ bǐjiào yíxià jiàgé.* — 가격을 한 번 비교해 보세요.

**구분:** `比较贵` = 비교적 비싸다(정도 부사), `比较价格` = 가격을 비교하다(동사).

## 3. 好像没有 (hǎoxiàng méiyǒu)

**好像** = ~인 것 같다/마치 ~처럼 보이다  
**没有** = 없다/하지 않았다(문맥에 따라)

- **这里好像没有大号的。**  
  *Zhèlǐ hǎoxiàng méiyǒu dàhào de.*  
  여기 큰 사이즈는 없는 것 같아요.
- **这两个好像没有什么区别。**  
  *Zhè liǎng ge hǎoxiàng méiyǒu shénme qūbié.*  
  이 두 개는 별 차이가 없는 것 같아요.
- **我好像没有见过他。**  
  *Wǒ hǎoxiàng méiyǒu jiànguo tā.*  
  저 그 사람을 본 적이 없는 것 같아요.
- **好像很贵。**  
  *Hǎoxiàng hěn guì.*  
  비싼 것 같아요.

## 4. 물건 비교 + 흥정

**跟那家店比起来，这里有点贵。可以便宜一点吗？**  
*Gēn nà jiā diàn bǐ qǐlái, zhèlǐ yǒudiǎn guì. Kěyǐ piányi yìdiǎn ma?*  
저 가게와 비교하면 여기가 좀 비싸네요. 조금 깎아주실 수 있나요?

**这件碎花连衣裙比那件长款连衣裙贵很多，可以便宜一点吗？**  
*Zhè jiàn suìhuā liányīqún bǐ nà jiàn chángkuǎn liányīqún guì hěn duō, kěyǐ piányi yìdiǎn ma?*  
이 플라워 원피스가 저 롱 원피스보다 훨씬 비싼데, 좀 깎아주실 수 있나요?

## 스스로 확인

1. 비교적 싸다 → `比较便宜`
2. 가격을 비교하다 → `比较价格`
3. A보다 B가 비싸다 → `B 比 A 贵`
4. 재고가 없는 것 같다 → `好像没有货` (이 문장은 새로 만든 연습 예문)
