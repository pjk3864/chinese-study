## 2026-11-17 추가 학습 포인트

- 元(yuán)은 2성.
- 一百는 보통 yì bǎi로 읽음.
- 가격 질문: 多少钱？(duōshao qián?)
- 옷의 양사: 件(jiàn)

위 항목은 **신규 학습 포인트**이며, 실제 오답으로 확인된 것은 아닙니다.


## 2026-11-17 추가 수업에서 확인된 실제 오답 (想 / 要)

| 원문 연습 문제 | 사용자 입력 | 수업 피드백 | 설명 |
|---|---|---|---|
| 明天我___去登山，已经安排好了。 | 想 | **要** | 이미 정해진 계획을 강조하는 연습 |
| 今天我___在家休息，不想出门。 | 要 | **想** | 쉬고 싶은 바람을 강조하는 연습 |

**주의:** 두 문항은 첨부한 수업의 목표에 따른 교정입니다. 실제 회화에서 想과 要는 맥락에 따라 겹치므로 항상 배타적인 정답은 아닙니다.

### 복습 대상 (오답으로 확정된 항목 아님)

- 人民币 = 통화명 / 元 = 화폐 단위 / 块 = 구어체 단위
- 比较贵 = 비교적 비싸다 / 比较价格 = 가격을 비교하다
- 跟…比起来 / 和…相比 / 比의 차이
- 好像没有 = 없는 것 같다
- 这样说自然吗？ = 이렇게 말하면 자연스러운가요?
